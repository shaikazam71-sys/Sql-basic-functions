# Sql-basic-functions
SQL Practice Queries
This repository contains my SQL practice queries and exercises completed as part of my Data Analytics learning journey. It includes solutions covering fundamental SQL concepts such as data retrieval, filtering, sorting, grouping, and aggregate functions using a sample movie database.

📚 Topics Covered

- SELECT Statements
- WHERE Clause
- ORDER BY
- GROUP BY
- Aggregate Functions (COUNT, AVG, MIN, MAX)
- ROUND Function
- Aliases (AS)

🛠️ Tools Used

- MySQL
- MySQL Workbench

🎯 Objective

The purpose of this repository is to document my SQL learning progress, strengthen my problem-solving skills, and build a portfolio that demonstrates my understanding of SQL for Data Analytics.
